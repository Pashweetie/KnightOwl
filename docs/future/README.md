# Future Features

This directory contains evaluated extensions that are outside the initial
release. These documents preserve constraints and research without authorizing
implementation.

A future feature moves into the product and architecture specifications only
after:

1. the initial release is complete;
2. a product requirement and measurable need are recorded;
3. privacy, security, operational, and compatibility effects are reviewed;
4. maintained libraries and standards are evaluated;
5. a dedicated ticket and approval are created.

Current future designs:

- [Peer-to-peer transport](PEER_TO_PEER_TRANSPORT.md)
- [Database scale options](DATABASE_SCALE_OPTIONS.md)
